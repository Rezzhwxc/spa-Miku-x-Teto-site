Frontend Developer. Отвечает за красоту интерфейса, адаптивную верстку и плавные анимации.

Главный архитектор визуальной части проекта и UI/UX Designer. Отвечает за интерактивную логику интерфейса, плавные CSS-анимации переходов и полную интеграцию музыкального плеера с дизайном страниц.

romazan

App Developer. Пишет чистый код и заставляет мобильные приложения летать.

Специалист по клиент-серверному взаимодействию, оптимизации и системам. Занимается тем, чтобы кодовая база фронтенда работала стабильно, быстро обрабатывала поступающие запросы к серверу и не нагружала вкладку браузера у пользователя.

Отвечает за реализацию маршрутизации страниц внутри нашего веб-приложения, асинхронные Fetch/API запросы, управление глобальным состоянием музыкального плеера, работу с хранилищем localStorage для сохранения сессий авторизации и грамотное кэширование данных треков для их мгновенной загрузки.

PLTNGM

Backend Developer. Мастер баз данных, настраивает API и держит сервера под полным контролем.

Разработчик серверной архитектуры, администратор баз данных и «сердце» бэкенда. Отвечает за безопасность пользовательских данных, быструю отдачу аудиофайлов с сервера, а также за хранение и обработку информации о лайках, пользователях и плейлистах.

Пишет серверную логику на Python с использованием Flask, проектирует и оптимизирует реляционную базу данных PostgreSQL через psycopg2, настраивает хэширование паролей с помощью Werkzeug, обрабатывает ошибки авторизации и обеспечивает стабильную работу всего проекта под нагрузкой.
